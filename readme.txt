ORM (Object-Relational Mapping)
Применяется для реляционных баз данных с структурированными данными и чёткими схемами. Позволяет:

1. представить информацию из базы как объекты, с которыми может работать язык программирования;
2. сопоставить поля из базы данных и свойства полученных объектов друг с другом;
создать интерфейс для выполнения задач CRUD — создания, чтения, модификации и удаления данных из базы.

ODM (Object-Document Mapping)
Используется для баз данных, ориентированных на документы (например, MongoDB, CouchDB). Позволяет:

автоматически преобразовывать объекты в документы базы данных (например, в формате JSON) и обратно;
упрощать управление данными, проверку и манипуляцию, избавляя разработчиков от необходимости писать запросы на уровне базы данных вручную.

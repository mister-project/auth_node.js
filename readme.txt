РЕШЕНИЕ ДЛЯ РЕГИСТРАЦИИ И АВТОРИЗАЦИИ ПОЛЬЗОВАТЕЛЕЙ
    Кроме сервера Express и mongoose (ORM/ODM) для подключения к mongoDb
установленны библиотеки для работы с паролями:
express-validator - проверка полей на заполнение
bcryptJs - хэширование паролей перед отправкой в БД
jsonwebtoken - генерация токенов при предоставлении доступа
=========

Для проверки работы решения (связи с Mongodb) необходимо использование VPN
Работоспособная актуальная версия находится в ветке https://github.com/mister-project/auth_node.js.git

Отправляемые запросы (тестировал через ПО Postman https://www.postman.com/):
1. На регистрацию пользователей POST - запрос http://localhost:5000/auth/registration
2. На авторизацию - POST - запрос http://localhost:5000/auth/login. После удачного запроса должен формироваться токен
3. На получение списка пользователей GET - запрос http://localhost:5000/auth/users . При выполнении этого запроса надо в закладке Headers внести строку Authorization и в столбце Value надо внести "Bearer + токен из п.2"

Сейчас в БД 2 пользователя - user c правами USER, которому список пользователей недоступен и admin с правами Admin, которому после выполнения Запроса GET - запроса http://localhost:5000/auth/users доступен список всех пользователей
